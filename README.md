# 🎨 Frontend UI Library

مجموعه‌ای از بخش‌های آماده و قابل استفاده‌ی رابط کاربری که با HTML، CSS و JavaScript خام ساخته شده‌اند.

A collection of ready-to-use frontend sections built with vanilla HTML, CSS, and JavaScript.

## ✨ ویژگی‌ها | Features

- هر نمونه مستقل است و بدون نصب وابستگی اجرا می‌شود.
- پشتیبانی از طراحی واکنش‌گرا و زبان فارسی/RTL در نمونه‌های مرتبط.
- تعاملات و انیمیشن‌ها با JavaScript خام.
- هر نمونه شامل `index.html`، `style.css` و `script.js` است.

## 📁 ساختار پروژه | Project Structure

```text
sections/
├── footer/    # Footer designs
├── login/     # Login designs
├── navbar/    # Navbar designs
└── register/  # Registration designs
```

## 🚀 نحوه‌ی استفاده | Usage

1. ریپو را کلون کنید یا پوشه‌ی طرح مورد نظر را دانلود کنید.
2. وارد پوشه‌ی نمونه شوید.
3. فایل `index.html` را مستقیماً در مرورگر باز کنید.
4. رنگ‌ها و اندازه‌ها را از متغیرهای ابتدای `style.css` شخصی‌سازی کنید.

```bash
git clone https://github.com/mahyardanesfahani/A_library_from_Frontend.git
cd A_library_from_Frontend
```
